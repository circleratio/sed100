# sed 100本ノック

GNU `sed` のコマンドを実際に手を動かして練習するための、ターミナル動作のクイズアプリです。
各問題で与えられた「入力」に対して `sed` コマンドを入力し、「期待する出力」と一致すれば正解となります。

## 必要環境

- Python 3
- `sed`（GNU sed 推奨。PATH上で実行可能であること）

## 使い方

```sh
python3 sed100.py
```

を実行すると、未正解の問題が順番に出題されます。各問題では、プロンプト `sed >` に対して
実際のターミナルで `sed ` の後に続けて打つ内容をそのまま入力します（例: `-n '2p'`）。
空白を含むスクリプトは `'...'` のようにクォートしてください。

### 特殊コマンド

出題中は以下のコマンドを入力できます。

| コマンド | 内容 |
| --- | --- |
| `:hint` | ヒントを表示する |
| `:answer` | 模範解答を表示する（正解として記録されます） |
| `:skip` | この問題をスキップする |
| `:status` | 現在の進捗を表示する |
| `:q` / `:quit` / `:exit` | 中断して終了する（進捗は保存される） |

### コマンドラインオプション

```sh
python3 sed100.py --list              # 進捗一覧（カテゴリ別の正解数）を表示
python3 sed100.py --reset             # 進捗をリセット
python3 sed100.py --problem N         # 問題番号 N のみを解く
python3 sed100.py --category NAME     # 指定したカテゴリの問題のみを解く
```

## 問題構成

全100問、以下のカテゴリで構成されています。

- 置換の基礎
- 行の削除
- 出力制御
- アドレス指定
- 正規表現
- グループ参照
- 複数行処理
- 分岐・応用
- 総合問題

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `sed100.py` | エントリーポイント。出題・採点・進捗表示などのCLIロジック |
| `problems.py` | 全100問の問題定義（`id` / `category` / `description` / `input` / `answer` / `hint`） |
| `runner.py` | ユーザーが入力した `sed` コマンドを実際に実行し、出力を得る |
| `progress.py` | 進捗（`progress.json`）の読み込み・保存・リセット |
| `progress.json` | 進捗の保存先（自動生成、gitignore対象） |

## 正解判定の仕組み

各問題の模範解答（`answer`）を実行して得られた出力を「期待する出力」とし、
ユーザーが入力したコマンドの実行結果と比較します。期待する出力はあらかじめ手で
書き起こしたものではなく、実行時に模範解答から動的に計算されるため、模範解答と
期待値がずれることはありません。
